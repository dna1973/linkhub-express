# LinkHub Express — Política de Privacidade

**Última atualização:** 22 de fevereiro de 2026

---

## 1. Introdução

O **LinkHub Express** ("nós", "nosso" ou "plataforma") está comprometido em proteger a privacidade dos seus usuários. Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos suas informações pessoais ao utilizar nossa plataforma disponível em https://linkhub-express.lovable.app.

Ao utilizar o LinkHub Express, você concorda com as práticas descritas nesta política.

---

## 2. Dados que Coletamos

### 2.1 Dados fornecidos pelo usuário

- **Dados de conta:** endereço de email, senha (armazenada de forma criptografada), nome completo
- **Dados de perfil:** nome de usuário, biografia, URL do avatar
- **Dados de conteúdo:** links adicionados (título, URL), configurações de design/tema

### 2.2 Dados coletados automaticamente

- **Dados de analytics:** visualizações de perfil, cliques em links
- **Dados técnicos:** endereço IP, user agent do navegador, tipo de dispositivo
- **Dados de geolocalização:** país, cidade (derivados do endereço IP)
- **Dados de navegação:** página de referência (referrer), ID de sessão

### 2.3 Dados de autenticação social

Ao fazer login com Google, recebemos:
- Nome completo
- Endereço de email
- URL da foto de perfil

Não armazenamos sua senha do Google nem acessamos outros dados da sua conta Google.

---

## 3. Como Usamos seus Dados

Utilizamos seus dados para:

| Finalidade | Base Legal |
|-----------|-----------|
| Criar e manter sua conta | Execução de contrato |
| Exibir seu perfil público | Execução de contrato |
| Fornecer analytics de acesso | Interesse legítimo |
| Melhorar a plataforma | Interesse legítimo |
| Enviar comunicações importantes | Interesse legítimo |
| Garantir segurança da plataforma | Interesse legítimo |

**Não vendemos, alugamos ou compartilhamos seus dados pessoais com terceiros para fins de marketing.**

---

## 4. Armazenamento e Segurança

### 4.1 Infraestrutura

- Seus dados são armazenados em servidores seguros operados pela Lovable Cloud
- Banco de dados PostgreSQL com criptografia em repouso
- Comunicações criptografadas via HTTPS/TLS
- Row Level Security (RLS) para isolamento de dados entre usuários

### 4.2 Medidas de Segurança

- Senhas criptografadas com bcrypt
- Tokens JWT com expiração automática
- Políticas de acesso no nível do banco de dados
- Autenticação obrigatória para operações de escrita

---

## 5. Compartilhamento de Dados

Seus dados podem ser compartilhados com:

- **Lovable Cloud:** infraestrutura de hospedagem e banco de dados
- **Google:** apenas quando você opta pelo login social (dados mínimos de autenticação)
- **Visitantes do seu perfil:** apenas informações que você escolheu tornar públicas (nome, bio, links)

---

## 6. Dados Públicos

Ao criar um perfil no LinkHub Express, as seguintes informações são visíveis publicamente:

- Nome de usuário
- Nome completo
- Biografia
- Avatar
- Links adicionados (título e URL)

Dados de analytics (visualizações, cliques, geolocalização de visitantes) são visíveis **apenas para o dono do perfil**.

---

## 7. Seus Direitos

Você tem os seguintes direitos sobre seus dados:

| Direito | Como Exercer |
|---------|-------------|
| **Acesso** | Visualize seus dados no Dashboard |
| **Retificação** | Edite seu perfil nas Configurações |
| **Exclusão** | Solicite a exclusão da sua conta |
| **Portabilidade** | Exporte seus dados via Dashboard |
| **Oposição** | Entre em contato conosco |

---

## 8. Cookies e Tecnologias Similares

O LinkHub Express utiliza:

- **Cookies de sessão:** para manter sua autenticação ativa
- **Local Storage:** para armazenar preferências do tema e sessão
- **Session ID:** para analytics agregados de visitantes

Não utilizamos cookies de rastreamento de terceiros nem ferramentas de publicidade.

---

## 9. Retenção de Dados

| Tipo de Dado | Período de Retenção |
|-------------|-------------------|
| Dados de conta | Enquanto a conta estiver ativa |
| Dados de analytics | 12 meses |
| Logs de acesso | 90 dias |
| Dados de sessão | Até expiração (7 dias) |

Após a exclusão da conta, seus dados são removidos em até 30 dias.

---

## 10. Menores de Idade

O LinkHub Express não é destinado a menores de 13 anos. Não coletamos intencionalmente dados de menores. Se tomarmos conhecimento de que coletamos dados de um menor, excluiremos as informações prontamente.

---

## 11. Alterações nesta Política

Podemos atualizar esta Política de Privacidade periodicamente. Alterações significativas serão comunicadas por email ou notificação na plataforma. A data da última atualização estará sempre indicada no topo deste documento.
