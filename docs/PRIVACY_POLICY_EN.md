# LinkHub Express — Privacy Policy

**Last updated:** February 22, 2026

---

## 1. Introduction

**LinkHub Express** ("we", "our", or "platform") is committed to protecting the privacy of its users. This Privacy Policy describes how we collect, use, store, and protect your personal information when using our platform available at https://linkhub-express.lovable.app.

By using LinkHub Express, you agree to the practices described in this policy.

---

## 2. Data We Collect

### 2.1 Data provided by the user

- **Account data:** email address, password (stored encrypted), full name
- **Profile data:** username, biography, avatar URL
- **Content data:** added links (title, URL), design/theme settings

### 2.2 Data collected automatically

- **Analytics data:** profile views, link clicks
- **Technical data:** IP address, browser user agent, device type
- **Geolocation data:** country, city (derived from IP address)
- **Navigation data:** referrer page, session ID

### 2.3 Social authentication data

When logging in with Google, we receive:
- Full name
- Email address
- Profile photo URL

We do not store your Google password or access any other data from your Google account.

---

## 3. How We Use Your Data

We use your data to:

| Purpose | Legal Basis |
|---------|------------|
| Create and maintain your account | Contract performance |
| Display your public profile | Contract performance |
| Provide access analytics | Legitimate interest |
| Improve the platform | Legitimate interest |
| Send important communications | Legitimate interest |
| Ensure platform security | Legitimate interest |

**We do not sell, rent, or share your personal data with third parties for marketing purposes.**

---

## 4. Storage and Security

### 4.1 Infrastructure

- Your data is stored on secure servers operated by Lovable Cloud
- PostgreSQL database with encryption at rest
- Communications encrypted via HTTPS/TLS
- Row Level Security (RLS) for data isolation between users

### 4.2 Security Measures

- Passwords encrypted with bcrypt
- JWT tokens with automatic expiration
- Database-level access policies
- Mandatory authentication for write operations

---

## 5. Data Sharing

Your data may be shared with:

- **Lovable Cloud:** hosting and database infrastructure
- **Google:** only when you opt for social login (minimal authentication data)
- **Your profile visitors:** only information you have chosen to make public (name, bio, links)

---

## 6. Public Data

When you create a profile on LinkHub Express, the following information is publicly visible:

- Username
- Full name
- Biography
- Avatar
- Added links (title and URL)

Analytics data (views, clicks, visitor geolocation) is visible **only to the profile owner**.

## 8. Cookies and Similar Technologies

LinkHub Express uses:

- **Session cookies:** to keep your authentication active
- **Local Storage:** to store theme preferences and session data
- **Session ID:** for aggregate visitor analytics

We do not use third-party tracking cookies or advertising tools.

## 9. Data Retention

| Data Type | Retention Period |
|-----------|-----------------|
| Account data | While account is active |
| Analytics data | 12 months |
| Access logs | 90 days |
| Session data | Until expiration (7 days) |

After account deletion, your data is removed within 30 days.
